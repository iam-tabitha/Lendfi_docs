# Lendfi Markdown Practice 

## Introduction 
Lendfi is a decentralized lending protocol that allows users to lend their crypto assets to earn interest or borrow assets by providing collateral.

Lendfi is designed for crypto users who want to **earn interest** on their idle assets or access liquidity without selling their crypto holdings.
Lendfi exists to provide a *simple and accessible way* for users to access decentralized lending and borrowing services without relying on traditional financial intermediaries. Learn more about how LendFi works in the [Introduction](introduction.md).
## Key features 
```text
- Crypto lending : Users can deposit supported assets and earn interest.
- Crypto borrowing : Users can borrow supported assets by providing collateral.
- Interest earnings : Lenders earn interest on assets supplied to the protocol.
- Collateralized loans : Borrowers provide collateral to secure their loans.
- User dashboard : Users can monitor their supplied assets, borrowed assets, interest, and account activity.
- Wallet connection: Users can connect a supported crypto wallet to access the protocol.
```
 ### How to get started
1. Connect your wallet : Connect a supported crypto wallet to access the Lendfi protocol.
2. Set up your account : Review the platform and complete any required account setup steps.
3. Explore the dashboard : Use the dashboard to view available assets, lending opportunities, borrowing options, and your account activity.
4. Choose an action : Select whether you want to lend assets to earn interest or borrow assets by providing collateral.
5. Confirm the transaction : Review the transaction details and confirm the transaction through your connected wallet.
    
| Requirement | Description |
| --- | --- |
| Wallet | A supported crypto wallet |
| Assets | Supported assets to lend or use as collateral |
| Network | A supported blockchain network |

For more information, `visit` the [LendFi website](https://example.com).
