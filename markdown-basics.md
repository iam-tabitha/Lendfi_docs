# Lendfi Markdown Practice 

## Introduction 
Lendfi is a decentralized lending protocol that allows users to lend their crypto assets to earn interest or borrow assets by providing collateral.

Lendfi is designed for crypto users who want to **earn interest** on their idle assets or access liquidity without selling their crypto holdings.
Lendfi exists to provide a *simple and accessible way* for users to access decentralized lending and borrowing services without relying on traditional financial intermediaries. Learn more about how LendFi works in the [Introduction](introduction.md).

## Before You Get Started

Before using LendFi, make sure you have completed the following:

- [ ] A supported crypto wallet.
- [ ] Supported crypto assets to lend or use as collateral.
- [ ] Access to a supported blockchain network.
- [ ] Enough funds to pay transaction fees.
      
## Key features 

1. **Crypto lending** 
- Users can deposit supported crypto assets.
- Users can earn interest on supplied assets.
2. **Crypto borrowing**
- Users can borrow supported assets by providing collateral.
3. **Interest earnings**
- Lenders earn interest on assets supplied to the protocol.
4. **Collateralized loans**
- Borrowers must provide collateral to secure their loans. 
5. **User dashboard**
- Users can monitor:
- Supplied assets
- Borrowed assets
- Earned interest
- Account activity.
6. **Wallet connection**
-  Users can connect a supported crypto wallet to access the protocol.

## How to Get Started

Follow these steps to begin using LendFi:

### 1. Connect Your Wallet

1. Open the LendFi application.
2. Click **Connect Wallet**.
3. Select your preferred supported wallet.
4. Approve the connection.

### 2. Set Up Your Account

- Review the platform and available features.
- Make sure you understand the requirements before proceeding.

### 3. Explore the Dashboard

Use the dashboard to view:
- Available assets
- Lending opportunities
- Borrowing options
- Your account activity

### 4. Choose an Action

Select what you want to do:
- Supply assets to earn interest.
- Borrow assets by providing collateral.

### 5. Confirm the Transaction

1. Review the transaction details carefully.
2. Confirm the transaction through your connected wallet.
3. Wait for the transaction to be processed on the blockchain.


> **Note:** Make sure your wallet is connected to a supported network before starting a transaction.

> **Warning:** Blockchain transactions may be irreversible once confirmed. Always review the transaction details and understand the risks before lending or borrowing assets.
